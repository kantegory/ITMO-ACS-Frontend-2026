## Темизация

В шапке доступны три режима: «По системе», «Светлая» и «Тёмная». По умолчанию сайт учитывает prefers-color-scheme. Ручной выбор сохраняется в localStorage и применяется на всех страницах. Событие storage синхронизирует выбор между открытыми вкладками; изменение системной темы учитывается в режиме «По системе».

Палитры заданы CSS-переменными в `src/style.css`. Меняются фон, поверхности, текст, границы, поля, кнопки, состояния фокуса и ошибки. `src/theme.js` задаёт data-theme и data-bs-theme, чтобы компоненты Bootstrap также использовали выбранную тему. Если localStorage недоступен, переключатель продолжает работать в текущей вкладке.

## Проверка

Проверены обе палитры, сохранение после перезагрузки, переход к форме входа, синхронизация между вкладками и соответствие системной настройке. На ширине 390 px меню с переключателем раскрывается без горизонтальной прокрутки. Сборка `npm run build` проходит. Дополнительный Lighthouse-аудит каталога в тёмном режиме дал 100/100 Accessibility; отчёты находятся в `audits`.

Скриншоты обеих тем и мобильного меню находятся в `screenshots`. Данные, API и фотографии сохранены из ЛР2; источники изображений и видео указаны в `src/seed.json` ([TheMealDB](https://www.themealdb.com/api.php)).
