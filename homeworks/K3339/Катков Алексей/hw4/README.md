## Иконки

В `public/icons.svg` находятся пять symbol с viewBox 0 0 24 24:

- `search`: кнопка поиска;
- `clock`: время приготовления в карточке и рецепте;
- `heart`: число лайков и кнопка «Нравится»;
- `bookmark`: сохранённые рецепты и кнопка сохранения;
- `user`: вход и личный кабинет.

Функция `icon()` в `src/icons.js` подключает symbol через use. Геометрия каждой иконки хранится один раз. Цвет берётся из currentColor, размер задаётся в em. Иконки следуют светлой и тёмной темам.

Декоративные SVG имеют aria-hidden и focusable="false". Текстовые подписи кнопок и ссылок сохранены; состояния лайка и сохранения передаются через aria-pressed.

## Проверка

`npm run build` проходит. XML спрайта содержит ровно пять символов; ссылки на все пять используются в DOM. В браузере проверены отрисовка и цвет в обеих темах, фильтрация до одного рецепта, вход с возвратом к рецепту, нажатие на SVG лайка и переключение сохранения. Скриншоты находятся в `screenshots`.

API и остальные функции сохранены из ЛР2, темы из ДЗ3. Фотографии и видео: [TheMealDB](https://www.themealdb.com/api.php), исходные ссылки в `src/seed.json`.
