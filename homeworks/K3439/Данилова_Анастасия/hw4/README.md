# ДЗ4 — SVG-спрайт

Данилова Анастасия, K3439. Вариант 4: сервис аренды недвижимости Snimu.

## Задание

Собрать SVG-иконки сайта в общий спрайт. Если иконок не было, добавить 3–5 иконок.

## Выполнение

В `img/sprite.svg` собраны шесть символов: `icon-home`, `icon-chat`, `icon-user`, `icon-pin`, `icon-sun`, `icon-moon`. У каждого символа заданы `id` и `viewBox`.

Иконка дома используется в шапке, чата и пользователя — в навигации, метка — рядом с адресами. Солнце и луна показываются на кнопке смены темы. В `js/theme.js` меняется ссылка на символ в зависимости от выбранной темы.

Пример подключения:

```html
<svg class="icon" aria-hidden="true">
  <use href="img/sprite.svg#icon-pin"></use>
</svg>
```

Размер задаётся классом `.icon`, цвет обводки — через `currentColor`. Поэтому иконки используют цвет окружающего текста и подходят для обеих тем. Декоративные изображения скрыты от скринридера, у кнопки смены темы есть текстовая подпись.

## Запуск

```bash
npm install
npm run server
```

В другом терминале из этой же папки:

```bash
python3 -m http.server 5500
```

Сайт: http://localhost:5500, API: http://localhost:3000. Внешний SVG-спрайт нужно открывать через HTTP-сервер.
