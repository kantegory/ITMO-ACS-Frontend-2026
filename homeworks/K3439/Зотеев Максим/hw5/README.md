# ДЗ5. Блокнот на Vue

Пример из методички по Vue и npm. На главной странице можно прочитать заметки и добавить свою. JSON Server хранит записи в `db.json`.

Для запуска нужен Node.js 22 (от 22.18) или 24.12 и новее. Из папки `hw5` установите зависимости:

```sh
npm ci
```

Запустите API в одном терминале:

```sh
npm run api
```

В другом терминале из той же папки запустите сайт:

```sh
npm start
```

Откройте [блокнот](http://localhost:8080). [Список записей API](http://localhost:3000/notes) доступен отдельно.

`npm run lint` проверяет код, `npm run build` собирает приложение в `dist/`. Для просмотра сборки запустите `npm run preview` при работающем API.
