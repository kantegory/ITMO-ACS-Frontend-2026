Катков Алексей Сергеевич, K3439, ИСУ 367275. Сайт рецептов «Щепотка» из ЛР2.

## Запуск

Нужен Node.js 24.13 или новее.

```sh
npm ci
npm start
```

Сайт: http://127.0.0.1:5174. API: http://127.0.0.1:3000/api. Демо-вход: `alexey@example.test` / `Recipe367275!`.

## Изменения

- Добавлены ссылка перехода к содержимому, именованная область поиска, aria-current, aria-busy и явная семантика списков.
- Декоративные изображения-ссылки убраны из последовательности Tab; название рецепта остаётся доступной ссылкой. Декоративная точка логотипа скрыта от вспомогательных технологий.
- Сообщения действий передаются через постоянную область status, ошибки - через alert. Форма связывается с сообщением ошибки; при несовпадении паролей поле получает aria-invalid и описание.
- После фильтрации и обновления действий восстанавливается фокус. Окно профиля получает фокус на поле имени, закрывается Escape и возвращает фокус на кнопку. Быстрое сохранение корректно обрабатывает анимацию открытия Bootstrap.
- Усилены контраст вторичного текста и плейсхолдеров, видимость фокуса и оформление в режиме forced-colors. Учтён prefers-reduced-motion.

## Проверка

```sh
npm run build
npm run audit:a11y
```

Аудит запускается при работающем сайте. На Windows скрипт использует установленный Microsoft Edge; при необходимости путь к Chromium-браузеру задаётся переменной `CHROME_PATH`. Другой адрес сайта задаётся через `AUDIT_URL`.

Lighthouse 13.6.0: каталог, рецепт, вход, регистрация и автор - **100/100 Accessibility**. Полные HTML/JSON-отчёты и сводка находятся в `audits`.

В Firefox DevTools выполнена проверка «Все проблемы». Первичный результат находится в `screenshots/firefox-audit.png`: отмечена декоративная точка логотипа. Для этого элемента добавлен aria-hidden; в итоговом дереве доступности точка отсутствует. После исправления Lighthouse повторно дал 100/100 на пяти страницах.

В браузере также проверены первый Tab на ссылку пропуска, переход Enter к main, сохранение фокуса и сообщение после фильтрации, фокус внутри модального окна, Escape, возврат фокуса после сохранения и доступная ошибка несовпадения паролей. Скриншот итогового Lighthouse находится в `screenshots/lighthouse.jpg`.

Моковое API, данные и фотографии сохранены из ЛР2. Источник фотографий и видео - [TheMealDB](https://www.themealdb.com/api.php); ссылки на записи указаны в `src/seed.json`.
