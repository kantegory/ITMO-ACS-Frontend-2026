## Запуск

```sh
npm ci
npm start
```

Сайт работает на http://127.0.0.1:5174, API на http://127.0.0.1:3000. Данные для входа подставляет кнопка «Заполнить данные».

## Клавиатура и скринридер

Первый Tab открывает ссылку «К содержимому». У полей есть видимые подписи, а у элементов управления виден фокус. Для сообщений о загрузке и результатах поиска используется область role="status". Ошибки связаны с полями через aria-describedby, неверное поле получает aria-invalid.

## Проверка

Клавиатурой проверены переход к содержимому, фильтрация и сообщение об ошибке при регистрации. После фильтрации фокус остаётся на кнопке «Найти».
Lighthouse после изменения оформления показал 100/100 на пяти страницах: каталог, рецепт, вход, регистрация и профиль автора. Результаты лежат в audits/.
В Firefox DevTools при первой проверке была замечена проблема с контрастом точки в логотипе. Скриншот в screenshots/firefox-audit.png относится к первому оформлению. В новом оформлении заголовок сайта отображается обычной текстовой ссылкой.

```sh
npm run audit:a11y
```
