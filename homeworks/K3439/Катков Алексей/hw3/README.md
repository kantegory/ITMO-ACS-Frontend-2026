# ДЗ3 - Светлая и тёмная темы

Катков Алексей Сергеевич, K3439.

## Запуск

```sh
npm ci
npm start
```

Сайт работает на http://127.0.0.1:5176, API на http://127.0.0.1:3000. Данные для входа подставляет кнопка «Заполнить данные».

## Цвета и переключатель

Цвета фона, текста, ссылок, границ и фокуса заданы CSS-переменными. Приложение меняет data-bs-theme на корневом элементе. Переключатель предлагает светлую, тёмную и системную темы. Режим хранится в localStorage. Системный вариант следует за prefers-color-scheme.

## Проверка

Светлая и тёмная темы проверены в браузере. После перезагрузки выбранная тема сохраняется. На узком экране страница помещается по ширине. Lighthouse для тёмного каталога показал 100/100 за доступность. Отчёт находится в audits/dark.report.html.

```sh
npm test
npm run build
```
