# ДЗ4 - SVG-спрайт

Катков Алексей Сергеевич, K3439.

## Запуск

```sh
npm ci
npm start
```

Сайт работает на http://127.0.0.1:5178, API на http://127.0.0.1:3000. Данные для входа подставляет кнопка «Заполнить данные».

## Спрайт

В public/icons.svg пять символов: search, clock, heart, bookmark и user. Элементы svg с use ссылаются на нужный symbol по его id. Цвет иконки наследуется от текста. Рядом есть подписи, поэтому SVG скрыты от скринридера через aria-hidden.

## Проверка

Иконки поиска и времени видны на главной. Иконки избранного, автора и времени видны на странице рецепта. Ссылки на все пять символов проверены в браузере.

```sh
npm test
npm run build
```
