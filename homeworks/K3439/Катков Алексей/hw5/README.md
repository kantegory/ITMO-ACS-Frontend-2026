# ДЗ5 - Заметки на Vue

Катков Алексей Сергеевич, K3439.

## Запуск

```sh
npm ci
npm start
```

Приложение работает на http://127.0.0.1:8080, JSON Server на http://127.0.0.1:3005.

## Приложение

На странице есть форма с названием и текстом и список заметок. Используются Vue, Vite и Bootstrap. Vue Router открывает NotesPage.vue. NoteForm.vue передаёт данные в представление, NoteCard.vue выводит одну запись. Хранилище Pinia обращается к JSON Server через Axios.

## Проверка

В браузере создана новая заметка, проверено её сохранение после перезагрузки и удаление из списка. Сборка прошла.

```sh
npm run build
```
