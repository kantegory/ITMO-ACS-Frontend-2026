# ДЗ2. Доступность в HTML

Сайт «Поварёшка» из ЛР2 с улучшенной доступностью. Что сделано:

- контраст текста доведён до WCAG AA (не меньше 4.5:1);
- ссылка «Перейти к основному содержанию», подписи навигации, `aria-current`;
- фильтры сгруппированы через `fieldset` / `legend`, у поиска и селектов есть подписи;
- `autocomplete` и `aria-describedby` в формах, `role="alert"` у ошибок;
- декоративные иконки и аватары скрыты от скринридеров (`aria-hidden`), у фото продуманный `alt`;
- `aria-pressed` у переключателей, `role="status"` у результатов поиска, уведомлений и загрузки;
- заметный фокус (`:focus-visible`) и `prefers-reduced-motion`.

Проверка: Lighthouse — 100 на всех страницах, axe-core — 0 нарушений, Firefox DevTools (проверены главная и страница рецепта) — без замечаний к сайту
(осталось только замечание к странице проигрывателя YouTube внутри `iframe`). Подробности — в `Отчёт.pdf`.

## Запуск

```bash
npm install
npm start
```

Сайт: <http://localhost:3000>, демо-аккаунт `demo@povaryoshka.ru` / `povar2026`.
