# ДЗ4. SVG-спрайт

Все иконки сайта «Поварёшка» собраны в общий спрайт `img/sprite.svg` — 17 простых символов
(поварёшка, лупа, сердечко, закладка, часы и т. д.), у каждого есть комментарий, что на нём нарисовано и где он используется.

Иконки подключаются через `<use>`:

```html
<svg class="icon" aria-hidden="true" focusable="false"><use href="img/sprite.svg#icon-heart"></use></svg>
```

В JS-шаблонах то же самое делает функция `icon('heart')` из `js/ui.js`.
Цвет и толщина линий задаются классом `.icon` в CSS, поэтому иконки подходят и к светлой, и к тёмной теме.

## Запуск

```bash
npm install
npm start
```

Сайт: <http://localhost:3000>. Внешний спрайт работает только при открытии через сервер, не через `file://`.
