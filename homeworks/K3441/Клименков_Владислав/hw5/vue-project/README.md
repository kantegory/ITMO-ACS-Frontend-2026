# Notes app (HW5)

Небольшое SPA-приложение для заметок на Vue 3 + Vite. Сделано по мануалу
дисциплины «Фронтенд-разработка» и примеру `20_vue3_example`, с исправлением
ряда ошибок исходного примера.

## Стек

- Vue 3 (Options API)
- Vite 5
- Vue Router 4
- Pinia + `pinia-persists` (сохранение состояния в `localStorage`)
- Axios
- Bootstrap 5
- `json-server` + `json-server-auth` в качестве мок-бэкенда

## Запуск

Установка зависимостей:

```bash
npm install
```

Запуск мок-сервера (в отдельном терминале):

```bash
npm run server
```

Сервер поднимается на `http://localhost:3000`. Заметки хранятся в `db.json`.

Запуск приложения в режиме разработки:

```bash
npm run dev
```

Приложение будет доступно на `http://localhost:5173`. Альтернативный вариант —
`npm start`, он запускает Vite на порту `8080`.

Сборка и проверка кода:

```bash
npm run build
npm run lint
```

## Структура

```text
src/
├── api/          # axios-инстанс и класс для работы с API заметок
├── stores/       # Pinia-хранилище заметок и настройка persist-плагина
├── router/       # маршруты приложения
├── layouts/      # BaseLayout — общая обёртка страниц
├── components/   # NoteCard
├── composables/  # форматирование дат
├── utils/        # разбор дат
└── views/        # NotesPage и AuthPage
```

## Маршруты

- `/` — список заметок и форма создания.
- `/login` — демонстрационная страница входа.
- `/private-notes` — тот же список заметок, но с проверкой флага входа.

Авторизация в примере демонстрационная: факт входа хранится в `localStorage`.
Мок-сервер при этом отдаёт заметки без JWT, поэтому приложение работает сразу
после запуска `npm run server`.

## Отличия от исходного примера

- Добавлен `"type": "module"`, чтобы Vite не предупреждал про CJS-сборку.
- `pinia-persists` остаётся с named-import `persist`: пакет распространяется
  в CommonJS, и default-import под Vite даёт `undefined` из-за флага
  `__esModule` в его экспорте.
- `createNote` больше не затирает массив заметок объектом ответа POST-запроса.
- Заметку можно удалить кнопкой-крестиком на карточке: отправляется
  `DELETE /notes/:id`, запись удаляется из `db.json`, а список обновляется
  без перезагрузки страницы.
- При создании заметки проставляется `createdAt`, а даты разбираются как
  локальные и сравниваются по календарным дням. Поэтому созданная сегодня
  заметка отображается как «сегодня», а не «вчера».
- Композаблы корректно обрабатывают отсутствующую или невалидную дату.
- Форма после отправки сбрасывает не только DOM, но и `v-model`-состояние.
- Форма входа отправляется через `@submit.prevent`, поэтому Enter не
  перезагружает страницу.
- URL API можно переопределить через `VITE_API_URL` (по умолчанию
  `http://localhost:3000`).
