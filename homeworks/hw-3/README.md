# TableBook — тёмная тема

## Что сделано

Сайт теперь поддерживает светлую и тёмную тему. По умолчанию тема подстраивается под системные
настройки устройства (`prefers-color-scheme`), а в шапке есть кнопка, которой можно переключить
тему вручную — выбор запоминается и при следующих заходах имеет приоритет над системной темой.

## Как это устроено

- `js/theme.js` — модуль `TableBookTheme`. При загрузке читает сохранённый в `localStorage` выбор
  темы; если его нет, берёт системную тему через `window.matchMedia('(prefers-color-scheme: dark)')`
  и ставит атрибут `data-bs-theme="dark"`/`"light"` на `<html>`. Пока пользователь не нажимал кнопку
  переключения, страница также следит за `change` этого media query, чтобы подхватывать смену темы в
  настройках ОС на лету.
- Подключение `theme.js` добавлено в `<head>` всех пяти страниц, до загрузки `style.css`. Скрипт
  выполняется синхронно и блокирует рендер на доли миллисекунды — ровно для того, чтобы тема была
  выставлена раньше первой отрисовки, без мигания неверным фоном.
- Кнопка переключения темы (`#theme-toggle`) добавлена в навбар каждой страницы. Клик по ней вызывает
  `TableBookTheme.toggle()`: он меняет `data-bs-theme` и сохраняет выбор в `localStorage`, после чего
  уже не трогается системной темой — пока пользователь явно не нажмёт кнопку ещё раз. Логика нажатия
  и обновления иконки/aria-атрибутов кнопки — в `js/common.js` (`setupThemeToggle`).
- `data-bs-theme` — встроенный механизм Bootstrap 5.3. Компоненты вроде `.card`, `.modal`, `.toast`,
  `.alert`, `.form-control`, `.badge` сами перекрашиваются под тёмный режим, без доп. кода.
- В `css/style.css` для кастомных блоков, которые Bootstrap не знает (цвета бренда, фильтр-сайдбар,
  карточки истории бронирований, карточки отзывов), добавлены переопределения под селектором
  `[data-bs-theme="dark"]`.

## Что изменилось в цветах

| Элемент | Светлая тема | Тёмная тема |
|---|---|---|
| Фон страницы (`--bg-soft`) | `#f1f2f4` | `#15181c` |
| Акцентный цвет (`--brand`) | `#c0392b` | `#e2574a` (ярче, чтобы не тускнеть на тёмном фоне) |
| Сайдбар с фильтрами | белый | `#1f2328` |
| Карточка отзыва | белый | `#1f2328` |
| Карточка истории бронирования | `#f6e2dc` | `#3a241f` |
