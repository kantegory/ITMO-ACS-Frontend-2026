# Отчёт — домашняя работа №3 (тёмная тема TableBook)

## Задача

Добавить сайту TableBook поддержку светлой и тёмной темы с автоматическим определением
системных настроек устройства и возможностью переключить тему вручную.

## Ход работы

Создан модуль `js/theme.js` (`TableBookTheme`). При загрузке он читает сохранённый в
`localStorage` выбор темы; если выбора нет — берёт системную тему через
`window.matchMedia('(prefers-color-scheme: dark)')` и ставит атрибут
`data-bs-theme="dark"`/`"light"` на `<html>`. До тех пор, пока пользователь не нажимал кнопку
переключения, страница также слушает событие `change` этого media query, чтобы подхватывать
смену темы в настройках ОС на лету.

Подключение `theme.js` добавлено в `<head>` всех пяти страниц до загрузки `style.css` и
выполняется синхронно — это блокирует рендер на доли миллисекунды, но зато тема выставляется
раньше первой отрисовки, без мигания неверным фоном.

В навбар каждой страницы добавлена кнопка переключения темы (`#theme-toggle`). Клик по ней
вызывает `TableBookTheme.toggle()`, который меняет `data-bs-theme` и сохраняет выбор в
`localStorage` — после этого тема уже не меняется автоматически вслед за системной, пока
пользователь не нажмёт кнопку ещё раз. Логика обработки клика и обновления иконки/aria-атрибутов
кнопки — в `js/common.js` (`setupThemeToggle`).

Используется встроенный механизм Bootstrap 5.3 — атрибут `data-bs-theme`: стандартные
компоненты (`.card`, `.modal`, `.toast`, `.alert`, `.form-control`, `.badge`) перекрашиваются
под тёмный режим без дополнительного кода. Для кастомных блоков, которые Bootstrap не знает
(цвета бренда, фильтр-сайдбар, карточки истории бронирований, карточки отзывов), в
`css/style.css` добавлены переопределения под селектором `[data-bs-theme="dark"]`.

## Вывод

Теперь сайт сам подстраивается под системную тему при первом заходе и запоминает явный выбор
пользователя между сессиями. Переключение реализовано на одном CSS-атрибуте (`data-bs-theme`),
что позволило переиспользовать встроенную поддержку тёмной темы Bootstrap и свести доработки
только к кастомным, нестандартным блокам интерфейса.
