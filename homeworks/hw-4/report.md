# Отчёт — домашняя работа №4 (SVG-спрайт иконок TableBook)

## Задача

Унифицировать работу с SVG-иконками на сайте TableBook: вынести уже существующие иконки
(солнце/луна для переключателя темы, встроенные прямо в JS как строки разметки) в общий
переиспользуемый источник и добавить недостающие иконки — звезду рейтинга, метку города,
иконку выхода из аккаунта.

## Ход работы

Создан файл-спрайт `icons/sprite.svg` — один SVG-файл с пятью `<symbol>`:
`icon-sun`, `icon-moon` (перенесены из `js/common.js` без изменения геометрии), `icon-star`
(рейтинг ресторана), `icon-pin` (город/расположение), `icon-logout` (выход из аккаунта в меню
пользователя). Сам `<svg>`-контейнер спрятан через `style="display:none"` и служит только
хранилищем определений иконок.

Везде, где раньше была вставлена целая SVG-разметка с путями, теперь используется короткая
ссылка на символ: `<svg class="icon" aria-hidden="true"><use href="icons/sprite.svg#icon-star"></use></svg>`.

Изменения по файлам:

- `js/common.js` — кнопка переключения темы берёт `icon-sun`/`icon-moon` в зависимости от
  текущей темы, ссылка «Выйти» в меню пользователя получила `icon-logout`;
- `js/data.js` — функция `renderStars`, которая раньше возвращала строку из символов
  `★`/`☆`, теперь рисует пять `<svg><use></use></svg>` с классом `rating-star-filled` или
  `rating-star-empty`;
- `js/search.js`, `js/restaurant.js` — рядом с городом в карточке ресторана и на странице
  ресторана добавлена иконка `icon-pin`.

В `css/style.css` добавлен базовый класс `.icon` (размер подстраивается под текущий размер
шрифта, заливка берётся из цвета текста через `fill: currentColor`) и классы
`.rating-star-filled`/`.rating-star-empty`, в том числе отдельное переопределение для тёмной
темы, чтобы пустые звёзды были видны на тёмном фоне.

## Вывод

Иконки перестали дублироваться как громоздкая разметка `path`-координат в разных JS-файлах —
теперь каждая иконка — это `id` символа в одном файле, подключаемый одной строкой `<use>`, а
изменить саму иконку можно в одном месте, в `sprite.svg`. Дополнительный эффект: замена
текстовых звёзд `★/☆` на SVG убрала зависимость вида рейтинга от системного шрифта браузера —
векторная иконка выглядит одинаково везде.
