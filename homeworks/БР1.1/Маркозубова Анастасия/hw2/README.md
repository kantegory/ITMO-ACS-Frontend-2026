# FinderJobs, ДЗ2

ДЗ2 основано на сайте из `LAB2` и не изменяет предыдущие работы.

## Что добавлено

- семантическая структура страниц;
- ссылка перехода к основному содержимому;
- доступные подписи полей и кнопок;
- управление интерфейсом с клавиатуры;
- CSS-переменные для цветов страницы;
- светлая и тёмная темы;
- переключатель темы с сохранением выбора в `localStorage`.

## Проверка

1. Открыть страницы через WebStorm или локальный сервер.
2. Проверить переход по элементам клавишей `Tab`.
3. Открыть Firefox DevTools и проверить вкладку Accessibility.
4. Запустить Lighthouse для мобильной и компьютерной версии.
5. Проверить, что тема сохраняется после обновления страницы.

## API

Для страниц, использующих данные ЛР2, API запускается из папки `HW2`:

```text
npm install
npm run api
```
