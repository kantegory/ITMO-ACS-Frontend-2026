# FinderJobs, ДЗ3

ДЗ3 основано на сайте из `HW2`. Цвета задаются CSS-переменными в `css\style.css`, переключение реализовано в `js\theme.js`.

## Темизация

- В `:root` задана светлая палитра, а `[data-theme="dark"]` переопределяет цвета страницы, карточек, баннера, ссылок и форм.
- При первом открытии тема выбирается по настройке устройства `prefers-color-scheme`.
- После ручного переключения сохранённый выбор имеет приоритет.
- Атрибут `data-bs-theme` переключает оформление компонентов Bootstrap, включая таблицы и формы.

## Проверка

1. Открыть страницы через WebStorm или локальный сервер.
2. Переключить тему кнопкой с луной или солнцем в шапке.
3. Открыть страницу входа и обновить её. Выбранная тема должна сохраниться.
4. В новом приватном окне проверить, что изначальная тема соответствует настройке устройства.

## API

Для страниц, использующих данные ЛР2, API запускается из папки `HW3`:

```text
npm install
npm run api
```
