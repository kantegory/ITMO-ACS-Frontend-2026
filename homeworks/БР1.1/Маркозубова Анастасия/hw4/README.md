# FinderJobs, ДЗ4: SVG-спрайт

ДЗ4 основано на сайте из `HW3`. Общий спрайт находится в `assets\sprite.svg` и содержит пять символов: `briefcase`, `search`, `user`, `sun`, `moon`.

Иконки подключены через `<svg><use href="assets/sprite.svg#search"></use></svg>`. Размер задаётся классом `icon`, цвет наследуется через `currentColor`. Декоративные иконки скрыты от экранного диктора атрибутом `aria-hidden="true"`.

Портфель используется на главной, поиск на страницах поиска, пользователь в резюме, солнце и луна в переключателе темы.

Открывайте сайт через HTTP-сервер WebStorm (Open in Browser), а не через `file://`: браузеры могут блокировать внешний SVG-спрайт при открытии с диска.

## Что добавлено

- семантическая структура страниц;
- ссылка перехода к основному содержимому;
- доступные подписи полей и кнопок;
- управление интерфейсом с клавиатуры;
- CSS-переменные для цветов страницы;
- светлая и тёмная темы;
- переключатель темы с сохранением выбора в `localStorage`.
- При первом открытии тема выбирается по настройке устройства `prefers-color-scheme`.
- После ручного переключения сохранённый выбор имеет приоритет.
- Атрибут `data-bs-theme` переключает оформление компонентов Bootstrap, включая таблицы и формы.

## Проверка

1. Открыть страницы через WebStorm или локальный сервер.
2. Проверить переход по элементам клавишей `Tab`.
3. Открыть Firefox DevTools и проверить вкладку Accessibility.
4. Запустить Lighthouse для мобильной и компьютерной версии.
5. Проверить, что тема сохраняется после обновления страницы.
