# FinderJobs, ДЗ5

Учебное приложение на Vue 3 и Vite. Компоненты: `src\App.vue`, `src\components\SiteHeader.vue`, `src\components\VacancyCard.vue`.

## Запуск

В терминале WebStorm из папки `Frontend\HW5`:

```text
npm install
npm run dev
```

Открыть адрес, показанный в терминале. Файл `index.html` напрямую с диска не запускать.

## Команды npm

- `npm install` устанавливает зависимости из package.json.
- `npm run dev` запускает сервер разработки.
- `npm run build` собирает приложение в dist.
- `npm run preview` запускает просмотр собранного приложения.
- `npm list --depth=0` показывает установленные зависимости.

## Компоненты Vue

Карточка получает данные через props и отправляет событие select через emit. App.vue хранит состояние ref, фильтрует вакансии через computed, связывает поля через v-model и выводит список через v-for. Подробности отображаются через v-if.

## Материалы для отчёта

Сохранить скриншоты в папке `screenshots`: главная страница, результат фильтрации, открытое описание вакансии, код компонентов в WebStorm и результат npm run build. Скриншоты должны показывать фактический запуск проекта.

Приложение использует демонстрационные данные. Маршрутизация и подключение API относятся к дальнейшему развитию проекта.
