# Домашняя работа 2. Доступность в HTML

**Исполнитель** — Даниил Кутуков, К3439.

Запустите сервер из ЛР2 и откройте [версию для ДЗ2](http://localhost:3000/hw2/).

- Ссылка для перехода к основному содержимому видна при фокусе. В навигации отмечена текущая страница.
- Подписи связаны с полями ввода. Диалог бронирования получил имя и описание, при открытии фокус переходит на дату. Escape закрывает диалог, фокус возвращается на кнопку бронирования.
- Обновления выдачи и истории объявляются через `role="status"`. Ошибки форм связаны с формами и получают фокус.
- Фотографии имеют альтернативные описания, а декоративные SVG скрыты от вспомогательных технологий. Контуры фокуса видны на ссылках, кнопках, полях и карточках.

## Проверка

Проверено 26 ноября 2026 года.

- В Firefox 142.0.1 через Accessibility Inspector проверена главная страница. В дереве есть область `main`, именованная основная навигация, ссылка пропуска, поле поиска с ролью `searchbox` и три подписанных списка фильтров с ролью `combobox`. [Документация Firefox Accessibility Inspector](https://firefox-source-docs.mozilla.org/devtools-user/accessibility_inspector/)
- В том же браузере проверены Tab и Enter для перехода к содержимому, объявление нового числа результатов, фокус поля даты при открытии диалога и возврат к кнопке после Escape. Проверка axe по правилам WCAG 2.0 и 2.1 уровней A и AA не показала нарушений на шести страницах и в открытом диалоге.
- Lighthouse первоначально обнаружил у ссылки «Все рестораны» контраст 4,21:1. Цвет ссылки заменён на зелёный из палитры интерфейса. Повторный аудит Lighthouse 12.8.2 в мобильном профиле дал следующие результаты.

| Страница | Accessibility | Пройденные автоматические проверки |
| --- | ---: | ---: |
| Каталог | 100/100 | 27 |
| Карточка ресторана | 100/100 | 24 |
| Вход | 100/100 | 22 |
| Регистрация | 100/100 | 22 |

Для повторной проверки откройте страницу в Firefox и выберите вкладку «Доступность» в DevTools. Аудит каталога можно запустить через `npx --yes lighthouse@12.8.2 http://localhost:3000/hw2/ --only-categories=accessibility --view`.
