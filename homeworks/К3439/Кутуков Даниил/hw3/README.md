# Домашняя работа 3. Темизация CSS

**Исполнитель** — Даниил Кутуков, К3439.

Запустите сервер из ЛР2 и откройте [версию для ДЗ3](http://localhost:3000/hw3/).

Светлая палитра объявлена в `lab1/styles.css`. Тёмная переопределяет те же CSS-переменные в `theme.css`. Контейнеры, текст, поля, кнопки и интерактивные состояния используют их в обеих темах. При первом посещении применяется `prefers-color-scheme`. Кнопка «Тёмная тема» меняет палитру, сохраняет выбор в `localStorage` и передаёт состояние через `aria-pressed`.
