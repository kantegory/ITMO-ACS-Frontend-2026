# Домашняя работа 4. SVG-спрайт

**Исполнитель** — Даниил Кутуков, К3439.

Запустите сервер из ЛР2 и откройте [версию для ДЗ4](http://localhost:3000/hw4/).

В `sprite.svg` собраны пять элементов `symbol`: геометка, поиск, календарь, аккаунт и звезда. В интерфейсе они подключаются через `use` с идентификатором символа. На главной странице видны геометка, поиск, аккаунт и звёзды рейтинга. Календарь находится у кнопки бронирования на странице ресторана. Иконки наследуют цвет текста через `currentColor`.
