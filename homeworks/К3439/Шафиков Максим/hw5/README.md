# ДЗ 5. Каталог тренировок «Качалочка»

Учебное приложение на Vue 3, созданное через `npm create vue@latest`.
Данные четырёх тренировок хранятся в `src/workouts.ts`.
`WorkoutFilter.vue` меняет выбранную категорию, а `WorkoutCard.vue` отображает отдельную тренировку.

## Запуск

Требуется Node.js 22.18+ в ветке 22 или Node.js 24.12+.

```sh
npm ci
npm run dev
```

Команда `npm run build` проверяет типы и собирает приложение в `dist/`.
