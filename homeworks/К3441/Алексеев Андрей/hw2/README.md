# ДЗ2. Доступность «Вектора»

[Отчёт в PDF](Отчёт.pdf)

Из этой папки запустите `python3 -m http.server 8202 --directory site` и
откройте <http://127.0.0.1:8202>. Чтобы проверить кабинеты, создайте два
тестовых аккаунта с ролями «Соискатель» и «Работодатель».

## Что изменилось

- Ссылка «К содержимому» переводит фокус к основному содержимому.
  После поиска фокус попадает на заголовок результатов.
- Элементы формы связаны с подписями и подсказками через `label` и
  `aria-describedby`. Поля почты, пароля, города и компании используют
  подходящие значения `autocomplete`.
- Количество вакансий, сохранение резюме и статусы отклика объявляются
  через постоянные области `role="status"`. Ошибки объявляются через
  `role="alert"`. У кнопок редактирования и удаления в кабинетах есть
  доступные имена с названием вакансии.
- На всех страницах есть заголовок первого уровня. Клавиатурный фокус
  выделяется контуром. Декоративные изображения исключены из дерева доступности.

## Проверка

В Firefox 153.0.1 открыт Accessibility Inspector. На скриншоте видны
дерево доступности каталога и порядок табуляции, включая переход
к содержимому и поле поиска. [Скриншот инспектора](evidence/firefox-accessibility.png)

В Chromium проверены переход по `Tab`, активация ссылки «К содержимому»
и поиск по `Enter`. После поиска фокус оказался на заголовке результатов.
Также проверены связь подсказки с полем пароля и заголовок страницы
при запросе отсутствующей вакансии.
