# ДЗ3. Светлая и тёмная темы «Вектора»

Из этой папки запустите `python3 -m http.server 8203 --directory site` и
откройте <http://127.0.0.1:8203>.

Сайт продолжает версию из ДЗ2. Переключатель «Тема» доступен на каждой странице.
При первом открытии тема следует `prefers-color-scheme`. Можно выбрать светлую
или тёмную вручную. Выбор сохраняется в localStorage и действует при переходах,
перезагрузке и в других вкладках сайта.

Цвета фона, текста, поверхностей, элементов каталога и кнопок заданы через
CSS-переменные. Скрипт задаёт `data-bs-theme` до загрузки CSS, а Bootstrap
использует то же значение для оформления полей и других элементов.
