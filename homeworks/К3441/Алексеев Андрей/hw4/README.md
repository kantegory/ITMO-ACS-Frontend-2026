# ДЗ4. SVG-спрайт «Вектора»

[Отчёт в PDF](Отчёт.pdf)

Из этой папки запустите `python3 -m http.server 8204 --directory site` и
откройте <http://127.0.0.1:8204>.

В `site/assets/icons.svg` собраны пять символов. Иконки логотипа, поиска,
фильтров, кабинета и выхода используют ссылки вида
`<use href="assets/icons.svg#search"></use>`. Цвет задаётся через
`currentColor` и меняется вместе с темой. Иконки дополняют видимые подписи
и скрыты от скринридера. Списки используют нативный указатель браузера.

Чтобы увидеть все пять иконок, зарегистрируйтесь, затем откройте каталог.
