# ДЗ5. npm и Vue

Самостоятельный проект «Вектор». Есть каталог с фильтрами и страница избранного.
Исходники находятся в [app](app), скриншоты и краткое описание компонентов — в [отчёте](Отчёт.pdf).

## Запуск

Нужен Node.js 22.18+ из ветки 22 или Node.js 24.12 и новее. Из папки `hw5` выполните:

```sh
cd app
npm ci
npm start
```

Откройте <http://127.0.0.1:8205>. Тот же сервер можно запустить командой
`npm run dev`. Команды `npm run build` и `npm run preview` собирают
приложение и показывают сборку на <http://127.0.0.1:8206>.

## Компоненты

- [CatalogFilters](app/src/components/CatalogFilters.vue) получает список отраслей через props и передаёт изменения фильтров через `v-model`.
- [VacancyCard](app/src/components/VacancyCard.vue) выводит данные вакансии и отправляет событие при выборе избранного.
- [VacancyList](app/src/views/VacancyList.vue) фильтрует вакансии, выводит состояния загрузки и использует `v-if` и `v-for`.
- [Хранилище Pinia](app/src/stores/vacancies.js) загружает демонстрационные данные через Axios и сохраняет избранное в браузере.
