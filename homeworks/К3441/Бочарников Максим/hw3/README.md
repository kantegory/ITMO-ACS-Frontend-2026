# ДЗ3 — темизация (CSS-переменные)

Две темы сайта VICE BITES с переключателем:

- **sunset** — светлая закатная (по умолчанию)
- **night** — тёмная

Тема сохраняется в `localStorage`. Если пользователь ещё не выбирал — учитывается `prefers-color-scheme`.

## Запуск

```bash
cd "homeworks/К3441/Бочарников Максим/hw3"
npm install
npm start
```
