# ДЗ4 — SVG-спрайт

Все иконки сайта VICE BITES собраны в один файл `img/sprite.svg` и подключаются через `<use href="img/sprite.svg#…">`.

## Иконки в спрайте

- `icon-heart` / `icon-heart-outline` — лайки
- `icon-search` — поиск
- `icon-user` — профиль / вход
- `icon-sun` / `icon-moon` — переключатель темы
- `icon-clock` — время готовки
- `icon-logout` — выход
- `icon-share` — поделиться
- `icon-play` — видео
- `icon-filter` / `icon-reset` — фильтры

## Запуск

```bash
cd "homeworks/К3441/Бочарников Максим/hw4"
npm install
npm start
```

Фронт — Live Server на эту папку (важно: HTTP, не `file://`, иначе внешний спрайт может не подтянуться).
