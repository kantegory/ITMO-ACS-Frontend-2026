## Запуск

Нужны Node.js 20.19+ или 22.12+ и npm. Все команды запускаются из папки `lr3`.

```bash
npm ci
npm run server
```

Во втором терминале:

```bash
npm run dev
```

Открыть [http://localhost:5173](http://localhost:5173). Моковое API слушает
`http://localhost:3000`. Для сборки выполнить `npm run build`, для просмотра сборки —
`npm run preview` при запущенном API. Другой адрес API можно задать через `VITE_API_URL`.

## Ход работы

1. Подключить Vue 3, Vite и Vue Router. В `App.vue` разместить общую навигацию и
   `RouterView`. Маршруты описать в `router.js`, а кабинет и сообщения защитить
   через `meta.auth` и `beforeEach`.
2. Перенести базу и правила маршрутов из ЛР2. В `api.js` создать общий экземпляр
   Axios. Перехватчик добавляет JWT в заголовок запроса. `useAuth` хранит
   реактивное состояние пользователя и управляет входом и выходом.
3. Перенести каталог и страницу объекта. Каталог отправляет фильтры параметрами
   GET-запроса и передаёт каждый объект в `PropertyCard`. Страница объекта берёт
   идентификатор из маршрута. Цена заявки пересчитывается через `computed`
   при изменении дат. Форма заявки открывается в диалоге.
4. Перенести кабинет и чат. `RentalTable` отображает заявки в кабинете и
   сделки на странице сообщений. `useRentals` загружает заявки в обеих ролях
   пользователя, а `useRequest` обрабатывает ожидание и ошибки запросов.
   В форме объявления данные уходят из `PropertyForm` через событие `save`.
5. Сохранить подписи полей, управление с клавиатуры и обе цветовые темы.
   `useTheme` синхронизирует выбранную тему с `localStorage`, а начальная
   палитра применяется до отрисовки Vue.

## Демонстрация

1. В каталоге применить фильтр и открыть «Уютная однушка у метро».
2. Войти под Анной. На странице объекта выбрать даты и отправить заявку.
3. Там же нажать «Написать владельцу», отправить сообщение и открыть историю сделок.
4. В кабинете проверить свою заявку, затем выйти и войти под Ириной.
   Одобрить входящую заявку на её объект.
5. Переключить тему и обновить страницу. Выбор темы должен сохраниться.

В Chrome проверены каталог с фильтрами, переключение и сохранение темы,
перенаправление с защищённого маршрута, вход, регистрация, отправка и одобрение
заявки, добавление объявления и отправка сообщения. `npm run build` проходит.

Мок-сервер работает локально и сохраняет изменения в `db.json`. Для чистой
демонстрации сначала сохранить копию этого файла.
