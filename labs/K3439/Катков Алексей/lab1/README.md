## Запуск

Node.js 24.13 или новее.

```sh
npm ci
npm start
```

Сайт: http://127.0.0.1:5173. `npm run build` собирает семь HTML-страниц в `dist`, `npm run preview` открывает сборку на http://127.0.0.1:4173.

Демо-вход: `alexey@example.test`, пароль `Recipe367275!`. Можно зарегистрировать отдельный учебный аккаунт.

## Страницы и функции

- `index.html` - каталог, поиск, фильтры по типу, сложности и ингредиенту, сортировка.
- `recipe.html?id=1` - фото, ингредиенты, шаги, видео, лайки, сохранение и комментарии.
- `login.html`, `register.html` - формы входа и регистрации с проверкой ввода.
- `profile.html` - сохранённые рецепты, собственные публикации, подписки, редактирование профиля в модальном окне Bootstrap.
- `author.html?id=2` - профиль автора, его рецепты и подписка.
- `publish.html` - публикация рецепта с ингредиентами и шагами.

Вёрстка: HTML, CSS, Bootstrap 5.3 и обычные JS-модули. Использованы адаптивная сетка, Collapse для мобильного меню и Modal для профиля. Внешние данные и серверная авторизация относятся к ЛР2: здесь адаптер `src/api.js` имитирует их в браузере. Данные хранятся в `localStorage` под ключом `shchepotka-lab1-data-v1`, текущий вход - в `sessionStorage`. Пароли учебных аккаунтов хранятся в виде SHA-256-хешей. Для этой локальной демонстрации используйте вымышленные данные.

Проверены сборка, совместная фильтрация, демо-вход, регистрация и несовпадение паролей, профиль и модальное окно, публикация, лайки, сохранение, комментарии и подписка. При ширине 390 px мобильное меню работает, горизонтальной прокрутки нет. Скриншоты находятся в `screenshots`.
