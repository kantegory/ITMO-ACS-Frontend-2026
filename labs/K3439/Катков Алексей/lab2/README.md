# ЛР2 - Каталог рецептов и API

Катков Алексей Сергеевич, K3439.

## Запуск

```sh
npm ci
npm start
```

Сайт работает на http://127.0.0.1:5174, API на http://127.0.0.1:3000. Данные для входа подставляет кнопка «Заполнить данные».

## Вариант 5. Рецепты

На главной странице есть поиск, фильтры и список рецептов. На странице рецепта показаны автор, фото, ингредиенты, шаги и комментарии. Видео открывается по кнопке. У автора есть профиль и список его рецептов.

## Сервер

Клиент отправляет запросы через fetch из src/api.js. JSON Server хранит рецепты, пользователей, комментарии и избранное. На сервере пароли хешируются через bcrypt, для входа выдаётся JWT. Сервер разрешает редактировать рецепт и профиль только их владельцу.

## Проверка

Прошли 10 тестов API и сборка. В браузере проверены поиск по ингредиенту, фильтры, вход и открытие рецепта.

```sh
npm test
npm run build
```
