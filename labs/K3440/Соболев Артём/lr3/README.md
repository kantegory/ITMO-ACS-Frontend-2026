# Fitness Platform - ДЗ5 и ЛР3

Соболев Артём, K3440. Перенос фитнес-платформы из ЛР1/ЛР2 на Vue 3.

## Запуск

Нужен Node.js 22.18+ или 24.12+ с npm. Проверка: `node --version` и `npm --version`.

В терминале из этой папки:

```sh
npm ci
npm run server
```

Во втором терминале из этой же папки:

```sh
npm start
```

Открыть http://127.0.0.1:8081. API работает на http://127.0.0.1:3001/api.
Остановить каждый процесс можно сочетанием Ctrl+C.
Для начала зарегистрируйте свой учебный аккаунт: исходная база не содержит пользователей.
Локальный `server/db.json` создаётся автоматически из `server/seed.json` и не попадает в Git.

```sh
npm run build     # производственная сборка в dist
npm run preview   # просмотр сборки; API также должен быть запущен
```

## Требования ЛР3

| Требование                   | Реализация                                                                                          |
| ---------------------------- | --------------------------------------------------------------------------------------------------- |
| Vue SPA и роутер             | `src/router/index.js`: 9 экранов, динамические адреса тренировок и статей, страница 404             |
| Внешний HTTP API через axios | `src/api.js`; отдельный Node.js API из ЛР2                                                          |
| Компонентный подход          | `src/components`: шапка, подвал, карточки, секция каталога, история, поле пароля, состояние запроса |
| Composable                   | `useAsync`, `useTheme`, `useProgress`                                                               |
| Состояние                    | Pinia: общая авторизация; восстановление сессии из localStorage                                     |
| Navigation guards и meta     | Защита `/account` и `/history`, возвращение после входа, заголовки маршрутов                        |

Здесь внешний API - отдельный HTTP-сервер приложения, перенесённый из ЛР2, а не сторонний публичный сервис.

## Структура

```text
public/assets/       изображения и SVG-иконки из ЛР1
src/api.js           общий axios-клиент
src/assets/          стили исходного приложения и адаптация к SPA
src/components/      переиспользуемые компоненты
src/composables/     общая реактивная логика
src/router/          маршруты, meta и проверка доступа
src/stores/          Pinia-хранилище авторизации
src/utils/           чистая функция расчёта прогресса
src/views/           страницы приложения
server/              API на json-server и json-server-auth
reports/             отчёты ДЗ5 и ЛР3, скриншоты
```

Сохранены каталог и фильтры тренировок, детали и видео, блог и статьи, регистрация и вход,
личный кабинет, история, статистика и светлая/тёмная тема. Разметка выводится Vue через
`v-for` и `v-if`, формы связаны через `v-model`, действия - через `@click` и `@submit.prevent`.
Библиотеки устанавливаются через npm, CDN не используется.

## Проверка вручную

1. Без входа открыть `/account`: должен открыться `/login?next=/account`.
2. Зарегистрироваться (пароль от 9 символов): откроется кабинет.
3. Выбрать «Кардио» и «До 20 минут» в каталоге: останутся 2 тренировки.
4. Открыть тренировку и нажать «Завершить тренировку»: появится подтверждение.
5. Открыть историю и кабинет: появятся запись и обновлённые показатели.
6. Переключить тему и обновить страницу: выбор сохранится.
7. Открыть блог, раскрыть дополнительные статьи, перейти в статью.
8. Выйти и проверить, что личные страницы снова требуют входа.
