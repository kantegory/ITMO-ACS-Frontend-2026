# ЛР1. «Поварёшка» — вёрстка на HTML, CSS и Bootstrap

Вариант 5: сервис для обмена рецептами и кулинарных блогов.

## Страницы

| Файл | Что на странице |
| --- | --- |
| `index.html` | поиск рецептов с фильтрами по типу блюда, сложности, ингредиентам и времени |
| `recipe.html` | страница рецепта: фото, ингредиенты, пошаговая инструкция, видео, лайки и комментарии |
| `author.html` | страница кулинара с подпиской и его рецептами |
| `profile.html` | личный кабинет: мои рецепты, сохранённые, подписки; модальные окна добавления рецепта и редактирования профиля |
| `login.html` | вход |
| `register.html` | регистрация |

## Запуск

Страницы можно открыть напрямую, но видео с YouTube встраивается только при открытии через локальный сервер:

```bash
npx serve .
# или
python3 -m http.server 8000
```

## Что использовано

- Bootstrap 5.3: сетка, навбар, offcanvas для фильтров на мобильных, вкладки, модальные окна, валидация форм;
- собственные стили в `css/style.css` (цвета и шрифты вынесены в CSS-переменные);
- `js/main.js`: фильтрация и сортировка карточек, лайки и подписки, проверка форм, добавление комментария.

Фотографии блюд взяты из открытой базы [TheMealDB](https://www.themealdb.com/).
