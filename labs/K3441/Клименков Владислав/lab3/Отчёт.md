## Задача

Перевести приложение RecipeHub с MPA на SPA на Vue 3: подключить роутер, реализовать работу с внешним API через Axios, разделить приложение на компоненты и вынести повторяющийся функционал в composables. Сохранить пользовательские сценарии ЛР2 и достижения ДР2–ДР4: доступность, светлую/тёмную темы и SVG-спрайт.

## Ход работы

Создана ветка `lab-3`, обновлены зависимости: Vite 8, Vue 3, Vue Router 4, Pinia 3, Axios, Bootstrap 5.3.8 из npm. Старые HTML-страницы и ES-модули заменены на SPA-структуру: `src/api`, `src/stores`, `src/composables`, `src/router`, `src/components`, `src/views`.

Реализованы: API-слой на Axios с interceptors, JWT и обработкой ошибок; Pinia-хранилища `auth` и `catalog`; composables `useTheme`, `useLiveRegion`, `useRecipeSearch`, `useBootstrapModal`; роутер с 7 маршрутами, 404-страницей, редиректами со старых URL, guards и meta. Компоненты и views разделены по ответственности. Сохранены доступность (skip-link, ARIA, live-region, фокус на `<main>` после перехода), темы (`system`/`light`/`dark`, `localStorage`, `data-bs-theme`) и SVG-спрайт (17 символов, все используются). Сервер оставлен только как API, добавлено автосоздание `db.json` из `db.seed.json`.

## Вывод

Приложение переведено на Vue 3 SPA с клиентским роутингом, Axios-слоем, Pinia-хранилищами и composable-функциями. Пользовательская функциональность ЛР2 и достижения ДР2–ДР4 сохранены. Ключевой результат — разделение ответственности: API-слой отвечает за HTTP, stores — за данные и социальные связи, composables — за повторяемое поведение, components — за отображение, views — за композицию экрана.
