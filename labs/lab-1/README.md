# TableBook — лабораторная работа №1

## Цель работы

Сверстать многостраничный сайт бронирования столиков в ресторанах без использования фреймворков и без обращения к серверу — вся логика работает на статичном HTML, CSS и JavaScript, а данные хранятся прямо в коде.

## Что сделано

Сайт состоит из пяти страниц: главная с поиском и фильтрами ресторанов, страница конкретного ресторана с меню, фото и отзывами, страницы входа и регистрации, личный кабинет пользователя с историей бронирований.

Данные о ресторанах лежат в `js/data.js` в виде массива объектов — название, кухня, город, цена, рейтинг, фотографии, меню и отзывы. Никакого backend нет, поэтому авторизация и бронирования эмулируются через `localStorage`: `js/auth.js` сохраняет в нём текущего пользователя, `js/profile.js` — список бронирований.

Разбивка по файлам:

- `index.html`, `js/search.js` — поиск и фильтрация ресторанов по кухне, городу и цене;
- `restaurant.html`, `js/restaurant.js` — страница ресторана, вкладки с меню/фото/отзывами, модальное окно бронирования;
- `login.html`, `register.html`, `js/auth.js` — вход и регистрация с проверкой полей на стороне клиента;
- `profile.html`, `js/profile.js` — личный кабинет, список бронирований и возможность их отменить;
- `js/common.js` — общие функции для всех страниц: навигация, рендер карточек;
- `css/style.css` — стили, вёрстка на Bootstrap с собственными доработками.

## Вывод

Получен рабочий прототип сайта, где вся бизнес-логика выполняется на клиенте. Такой подход подходит только для демонстрации интерфейса — реальных данных между пользователями или устройствами он не синхронизирует, что и стало отправной точкой для следующей лабораторной, где появляется сервер.
