# FinderJobs, ЛР1

Вёрстка HTML, CSS, Bootstrap и интерактивность JavaScript. Сайт работает без API: начальные демонстрационные данные находятся в js\demo-data.js, изменения сохраняются в localStorage.

## Запуск

Открыть index.html через Open in Browser в WebStorm либо запустить:

```powershell
cd "labs/БР1.1/Маркозубова Анастасия/lab1"
npx.cmd --yes http-server . -p 5500
```

Адрес: http://127.0.0.1:5500/index.html.

## Аккаунты для проверки

- Соискатель: candidate@example.com, пароль Test1234!
- Работодатель: employer@example.com, пароль Test1234!

Это демонстрационная авторизация в браузере, а не защита данных на сервере. Для регистрации используйте новую почту. Данные сохраняются в этом браузере для текущего адреса сайта.

## Проверка

Вход, регистрация, ошибки паролей, поиск по тексту и фильтры отрасли/зарплаты/опыта, подробности вакансии, сохранение резюме, отклик, просмотр отклика работодателем, создание/изменение/удаление своей вакансии. После обновления страницы данные должны сохраняться.

## Код для защиты

- js\local-store.js: localStorage, демонстрационные пользователи и операции с данными.
- js\script.js: формы, фильтрация, карточки, резюме, отклики и редактор вакансий.
- js\header.js: меню и выход из аккаунта.
- css\style.css: оформление и адаптивность.
