# FinderJobs, ЛР2

HTML, Bootstrap, JavaScript fetch, JSON Server и json-server-auth. Все страницы и API обслуживаются одним сервером.

## Запуск

```powershell
cd "D:\Study\SEM 7\Frontend\LAB2"
npm install
npm start
```

Открыть http://127.0.0.1:3000/index.html. Терминал оставить открытым. Остановка: Ctrl+C.

## Проверка

1. Зарегистрировать работодателя и создать вакансию с компанией, зарплатой, отраслью, опытом, описанием и требованиями.
2. Проверить изменение и удаление своей вакансии.
3. Выйти, зарегистрировать соискателя и сохранить резюме.
4. Открыть поиск, проверить название, отрасль, минимальную зарплату и опыт.
5. Открыть выбранную вакансию и отправить отклик.
6. Проверить отклик в кабинете соискателя, затем войти работодателем и проверить входящий отклик.
7. Проверить поиск сотрудников по должности или навыку.
8. Проверить неверный пароль, несовпадающие пароли регистрации и повторный отклик.

Данные сохраняются в db.json. Предустановленные вакансии демонстрационные. Для проверки входящих откликов создать вакансию из аккаунта работодателя.

Токен хранится в localStorage, передаётся в Authorization: Bearer и проверяется на сервере. Сервер ограничивает операции по роли и владельцу. Без токена закрытые страницы переводят на вход, API отвечает 401. Это учебная моковая авторизация.

## Автоматические проверки

```text
node test-api.cjs
node test-browser.cjs
```

Проверки используют временные копии базы. Браузерная проверка запускает установленный Google Chrome и требует свободного порта 3000 (перед проверкой остановить npm start).

Проверены регистрация, вход, токен, резюме, фильтры, создание/изменение/удаление вакансии, отклики, защита чужих данных и мобильная ширина 375 px.
