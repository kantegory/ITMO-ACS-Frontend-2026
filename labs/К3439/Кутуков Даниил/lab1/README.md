# Лабораторная работа 1. HTML, CSS и Bootstrap

**Исполнитель** — Даниил Кутуков, К3439.

Вариант 1. «Столик» — поиск ресторанов Санкт-Петербурга и бронирование столиков.

## Запуск

В этой папке выполните `npx --yes http-server . -p 4171 -c-1` и откройте [главную страницу](http://localhost:4171/). CSS Bootstrap 5.3.8 входит в проект. Для локальной регистрации используются DOM-хранилище и Web Crypto, поэтому приложение открывается через localhost.

## Сценарий проверки

1. Установите фильтры кухни, района и среднего чека. Введите название и проверьте сброс фильтров.
2. Откройте карточку ресторана. В ней есть адрес, часы работы, фото, меню и отзывы.
3. Зарегистрируйте демонстрационный аккаунт. Откройте личный кабинет, выйдите и снова войдите.
4. Вернитесь в ресторан, откройте диалог и выберите будущую дату, время и число гостей.
5. Зайдите в историю, отмените бронь и обновите страницу. История, аккаунт и статус сохраняются в браузере.

Названия и данные ресторанов демонстрационные. Источник фотографий — [Unsplash](https://unsplash.com/).
