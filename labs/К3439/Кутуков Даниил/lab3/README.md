# Лабораторная работа 3. SPA на Vue

**Исполнитель** — Даниил Кутуков, К3439.

«Столик» из ЛР1 и ЛР2 перенесён на Vue 3. Vue Router открывает каталог, карточку ресторана, вход, регистрацию, кабинет и историю бронирований. Маршруты кабинета и истории проверяются через navigation guard. После входа посетитель возвращается на запрошенную страницу.

## Запуск

1. В папке соседней работы `lab2` выполните `npm ci` и `npm start`. API доступен на порту 3000 и хранит бронирования в рабочей JSON-базе.
2. В папке `lab3` выполните `npm ci`, затем `npm run dev`.
3. Откройте [Столик](http://localhost:4173/). Команда `npm run build` создаёт production-сборку, а `npm run preview` запускает её с тем же прокси.

## Структура

- `src/views` содержит представления маршрутов. `src/components` — фильтры, карточку ресторана, диалог бронирования, список броней, навигацию и SVG-иконку.
- `useRequest` управляет загрузкой и ошибками для представлений и форм. `useTheme` синхронизирует CSS-тему с настройками посетителя.
- Pinia хранит текущего пользователя. Axios обращается к JSON Server из ЛР2. Общие стили и фотографии берутся из ЛР1, темизация и SVG-спрайт переиспользуются из ДЗ3 и ДЗ4.

Для проверки откройте карточку ресторана, зарегистрируйтесь, создайте бронь и отмените её через историю. Обновите страницу и проверьте сохранённый статус. Проверьте фильтры каталога и переход в кабинет без входа.
