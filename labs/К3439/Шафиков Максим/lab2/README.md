# Качалочка — лабораторная работа № 2

Клиент из ЛР1 получает данные через `fetch` из мокового API на JSON Server. Каталог и журнал доступны гостям. Для просмотра и изменения плана и истории нужен вход.

## Запуск

Требуются Node.js 20 или новее и pnpm.

```sh
pnpm install --frozen-lockfile
pnpm start
```

Начальные тренировки и статьи лежат в `db.json`. При первом запуске сервер создаёт рабочую копию `db.local.json`. В ней хранятся профили, планы и история. Данные браузера из ЛР1 относятся к первой версии сайта. В ЛР2 создаётся новый профиль.

## Маршруты API

| Метод | Маршрут | Назначение |
| --- | --- | --- |
| GET | `/api/workouts`, `/api/workouts/:id` | Каталог и отдельная тренировка |
| GET | `/api/articles`, `/api/articles/:id` | Список статей и отдельная статья |
| POST | `/api/auth/register`, `/api/auth/login` | Регистрация, вход и выдача токена |
| GET | `/api/me` | Профиль текущего пользователя |
| POST | `/api/auth/logout` | Завершение сессии |
| GET | `/api/activity` | План и история текущего пользователя |
| POST | `/api/activity/plan` | Добавление тренировки на дату |
| DELETE | `/api/activity/plan/:id` | Удаление занятия из плана |
| POST | `/api/activity/plan/:id/complete` | Перенос занятия из плана в историю |
| POST | `/api/activity/complete` | Отметка на странице тренировки |
