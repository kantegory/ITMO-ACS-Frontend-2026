# Качалочка — лабораторная работа 3

Одностраничное приложение на Vue 3. Vue Router переключает каталог, карточки тренировок, журнал, формы входа и регистрации и личный кабинет. Клиент обращается к API ЛР 2 через Axios. Обработчики загрузки, сохранения и состояния сессии вынесены в composables.

## Запуск

Требуется Node.js 22.18+ в ветке 22 или Node.js 24.12+.

```sh
npm ci
npm run build
npm start
```

Приложение и API доступны на `http://127.0.0.1:3000`. Для разработки запустите `npm run api` и `npm run dev` в двух терминалах. Vite проксирует запросы `/api` на порт сервера.

Начальные тренировки и статьи находятся в `db.json`. При первом запуске сервер создаёт `db.local.json` для профилей, плана и истории. Файлы базы ЛР 2 находятся в её собственной папке.
