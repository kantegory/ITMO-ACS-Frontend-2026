# ЛР1. Вектор — сайт поиска работы

Вариант 2. HTML, CSS, Bootstrap и JavaScript.

Из этой папки запустите локальный HTTP-сервер.

```sh
python3 -m http.server 8000
```

Откройте <http://localhost:8000>. Для проверки создайте два аккаунта с разными
адресами, один с ролью соискателя, другой с ролью работодателя.

- Соискатель может найти вакансию по запросу, отрасли, опыту и зарплате,
  открыть описание, сохранить резюме и откликнуться.
- Работодатель может добавить, изменить и удалить свои вакансии.
- Вход, резюме, отклики и новые вакансии хранятся в localStorage текущего браузера.
  Для демонстрации используйте вымышленные данные.
