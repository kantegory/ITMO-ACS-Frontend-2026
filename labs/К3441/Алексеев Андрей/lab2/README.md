# ЛР2. Вектор — работа с API

В интерфейс включены доработки из ДЗ2–ДЗ4. В меню «Тема» доступны системный, светлый и тёмный режимы. Выбор сохраняется в браузере.

Для запуска из этой папки нужен Node.js 22 или новее.

```sh
npm ci
npm start
```

Откройте <http://127.0.0.1:3102>. Команда запускает JSON Server и раздаёт
HTML, CSS и JavaScript из `public`. Данные сохраняются в `.runtime/db.json`,
который при первом запуске создаётся из `server/db.seed.json`.

- Каталог и страницы вакансий загружаются через `fetch`.
- Регистрация и вход работают через `json-server-auth`. Для резюме, откликов
  и управления вакансиями сервер проверяет JWT, роль и владельца записи.
- На странице вакансии можно пересчитать зарплату из рублей в USD или EUR.
  Курсы загружаются из [ExchangeRate-API](https://www.exchangerate-api.com/docs/free).
  Функция доступна при подключении к интернету.
- Для проверки создайте отдельные аккаунты соискателя и работодателя.
  При перезапуске сервера сессии обновляются. Можно задать постоянный
  секрет через переменную окружения `JWT_SECRET`.
- Порт задаётся переменной окружения `PORT`.
