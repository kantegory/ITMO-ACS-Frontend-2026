# ЛР3. Вектор — SPA на Vue

Для запуска из этой папки нужен Node.js 22.12+ или 24+.

```sh
npm ci
npm run dev
```

Откройте адрес Vite из терминала, обычно <http://127.0.0.1:5173>.
Скрипт одновременно запускает Vite и JSON Server. Vite проксирует
`/api` на JSON Server (порт 3103 по умолчанию).

Для запуска собранного приложения на одном порту выполните команды ниже
и откройте <http://127.0.0.1:3103>.

```sh
npm run build
npm start
```

- Vue Router открывает каталог, отдельную вакансию, вход, регистрацию
  и кабинеты. Navigation guard проверяет сессию и роль.
- Каталог, карточки, фильтры, редактор вакансии и конвертер валют
  собраны из Vue-компонентов. `useSession` управляет сессией,
  `useRequest` обрабатывает состояние запроса.
- Axios обращается к JSON Server и к открытому
  [ExchangeRate-API](https://www.exchangerate-api.com/docs/free)
  для пересчёта зарплаты в USD и EUR.
- Для проверки зарегистрируйте отдельные аккаунты соискателя и работодателя.
  Моковый API сохраняет данные в `.runtime/db.json`. При перезапуске API
  нужно войти снова либо задать постоянный секрет через `JWT_SECRET`.
