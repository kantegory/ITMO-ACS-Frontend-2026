# VICE BITES — Лабораторная работа 1

Сайт обмена рецептами и кулинарных блогов.

Вариант курса: *«Сервис для обмена рецептами и кулинарных блогов»*.

## Стек

- HTML5 (семантика)
- CSS3 + CSS-переменные (своя палитра, без «дефолтного Bootstrap»)
- Bootstrap 5.3 (сетка, навбар, табы, модалки)
- Vanilla JS (фильтры, лайки, комментарии, подписка)

Бэкенда нет: данные в `js/data.js`.

## Структура

```
lab1/
  index.html      — каталог + фильтры
  login.html      — вход
  register.html   — регистрация
  profile.html    — ЛК: сохранённые, публикации, подписки
  recipe.html     — страница рецепта (?id=r1 … r8)
  css/styles.css
  js/data.js
  js/main.js
  README.md
```

## Как открыть

**Вариант 1 — просто открыть файл**

Открой `index.html` в браузере (двойной клик или «Open with Live Server»).

**Вариант 2 — live-server (удобнее для навигации)**

```bash
npx --yes live-server "labs/К3441/Бочарников Максим/lab1"
```

или из папки `lab1`:

```bash
npx --yes live-server
```

## Что сделано

- Бренд **VICE BITES**, закатная палитра, тёмные контуры, кинематографичный hero
- 8 рецептов на русском с тропическим уклоном
- Фильтры: тип, сложность, поиск, чипы ингредиентов
- Лайк toggle, комментарии в список, подписка на автора, Bootstrap-модалки
- Единый header/footer, адаптив desktop + mobile
